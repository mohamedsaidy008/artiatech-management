=========================================
الدرس الرابع: تزامن النقاشات اللحظي وميزة الحذف
=========================================

أهلاً بك! في هذا الدرس سنشرح كيف برمجنا نظام الدردشة المخصص لكل مشروع (Project-Specific Chat) في الملف (`js/discussions.js`) مع دعم التحديث اللحظي وإتاحة حذف الرسائل.

1. فصل النقاشات لكل مشروع بشكل مستقل
------------------------------------
بدل خلط النقاشات في غرفة واحدة، قمنا بتنظيم قاعدة البيانات بحيث يكون لكل بطاقة مهمة في لوحة المخططات غرفتها الخاصة، وتُخزن محادثاتها في المسار:
   `discussions/{taskId}/{messageId}`

عند اختيار المستخدم لمشروع من القائمة اليمنى، نقوم بقراءة المعرف الفريد الخاص به (taskId) ثم نقوم بتفعيل المستمع الحقيقي (Listener) على محادثات هذا المشروع تحديداً:
   const chatRef = ref(db, `discussions/${taskId}`);

2. التحديث اللحظي للرسائل (Real-time Messaging)
-----------------------------------------------
نستخدم دالة `onValue` للاستماع المباشر للرسائل. بمجرد إرسال أي عضو لرسالة، يتم تحديث شاشة الشات لجميع المستخدمين المشتركين فوراً:
   activeChatListener = onValue(chatRef, (snapshot) => {
       const messages = snapshot.val();
       // ... رسم الرسائل في الـ DOM ...
       // النزول التلقائي لأسفل الشات
       mainChatBody.scrollTop = mainChatBody.scrollHeight;
   });

3. إرسال الرسائل وبناء المعرّفات العشوائية
-----------------------------------------
عند كتابة رسالة وضغط إرسال، نستخدم الدالة `push()` لإنشاء معرف فريد عشوائي ومضمون للرسالة الجديدة، مما يمنع تعارض الرسائل عند إرسالها في نفس الثانية:
   const chatRef = ref(db, `discussions/${selectedTaskId}`);
   const newMsgRef = push(chatRef); // توليد معرف فريد تلقائي
   await set(newMsgRef, {
       id: newMsgRef.key,
       senderId: user.id,
       senderName: user.name,
       message: text,
       timestamp: Date.now()
   });

4. ميزة حذف الرسائل (Message Deletion)
--------------------------------------
لحماية النقاشات من الأخطاء الإملائية أو الرسائل غير اللائقة، قمنا بإتاحة حذف الرسالة.
- من يستطيع الحذف؟: كاتب الرسالة نفسه (أي أن `senderId` للرسالة يساوي معرف المستخدم الحالي) **أو** إذا كان المستخدم هو المدير (Role: Admin).
- الكود البرمجي للتحقق:
   const canDelete = isMyMsg || user.role === "admin";
   const deleteHTML = canDelete ? `<button class="delete-msg-btn" data-id="${msg.id}">حذف 🗑️</button>` : "";
   
عند قيام العضو المؤهل بالضغط على زر الحذف، نقوم باستدعاء الدالة `remove()` من فايربيس لحذف مسار هذه الرسالة بالذات من قاعدة البيانات:
   await remove(ref(db, `discussions/${taskId}/${msg.id}`));
   
بمجرد حذفها من السحابة السحابية لفايربيس، يتم مسحها من واجهات جميع الأعضاء المفتوحة شاشاتهم تلقائياً وبلحظتها!

تلميح للمبتدئين:
دمج فكرة النقاشات المخصصة داخل لوحة العمل يمنع تشتت النقاشات الإدارية مع الدردشات العامة، ويسهل على أي عضو جديد ينضم للمشروع قراءة أرشيف النقاش ومعرفة ما تم إنجازه بسهولة.
