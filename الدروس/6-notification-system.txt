=========================================
الدرس السادس: نظام الإشعارات اللحظي وتنبيهات المتصفح
=========================================

مرحباً بك في الدرس الأخير! سنشرح هنا كيف قمنا ببناء نظام الإشعارات الفورية المدمج في التطبيق وكيف وظفنا بروتوكولات المتصفح لإرسال تنبيهات حتى لو كان العضو يتصفح موقعاً آخر.

1. هندسة الإشعارات اللحظية (Notification Architecture)
------------------------------------------------------
يعمل نظام الإشعارات لدينا على مستويين متكاملين:
1. إشعارات داخل التطبيق (In-App): تظهر كرقم أحمر فوق جرس الإشعارات ورسالة منبثقة ملونة (Toast) أسفل الشاشة.
2. إشعارات النظام (System Push): تظهر كتنبيه من نظام ويندوز أو الماك أو الهاتف عبر المتصفح مباشرة.

2. تتبع الإشعارات في قاعدة البيانات
---------------------------------
يتم تخزين الإشعارات تحت مسار فرعي خاص بكل مستخدم:
   `notifications/{userId}/{notiId}`
   
وعند فتح أي صفحة في المنظومة، يقوم المستمع الموحد في الملف (`js/auth-guard.js`) بالاستماع الفوري لهذا المسار:
   const notiRef = ref(db, `notifications/${userId}`);
   onValue(notiRef, (snapshot) => {
       const notis = snapshot.val();
       // حساب عدد الرسائل غير المقروءة لتحديث شارة الجرس (Badge)
       const unreadCount = notiArray.filter(n => !n.read).length;
       badge.textContent = unreadCount;
   });

3. إرسال الإشعارات وعرض التوست (Toast Messages)
----------------------------------------------
قمنا بتصميم دالة برمجية مخصصة لإنشاء الرسائل الطائرة في الواجهة تلقائياً:
   export function showToast(message, type = "info") {
       const toast = document.createElement("div");
       toast.className = `toast toast-${type}`;
       toast.innerHTML = `<span>...</span>`;
       container.appendChild(toast);
       
       // إزالتها بحركة انسيابية بعد 4 ثوانٍ
       setTimeout(() => { toast.remove(); }, 4000);
   }

4. استدعاء نظام المتصفح الأصلي (Native Notification API)
-------------------------------------------------------
لعرض إشعار للمستخدم حتى لو كان يفتح علامة تبويب أخرى أو يعمل على برنامج فوتوشوب مثلاً، نقوم بطلب إذن المتصفح أولاً عند تسجيل الدخول:
   if ("Notification" in window && Notification.permission === "default") {
       Notification.requestPermission();
   }

وعند إرسال أي إشعار جديد للعضو، نتحقق من موافقته السابقة ونطلق تنبيه النظام الفوري:
   if ("Notification" in window && Notification.permission === "granted") {
       new Notification("استوديو ارتياتك", {
           body: message,
           icon: "./logo.png" // مسار أيقونة الاستوديو
       });
   }

5. متى يتم إرسال الإشعارات تلقائياً؟
---------------------------------
في الكود، قمنا بزرع دالة `sendNotification()` في الأماكن الهامة:
- عند قيام الأدمن بتعيين مهمة جديدة لعضو في لوحة المخططات.
- عند إرسال تعليق جديد في شات مشروع معلق (تُرسل لباقي المنفذين تلقائياً).
- عند موافقة الأدمن على طلب سحب مالي أو رفضه لتنبيه العضو.

تلميح للمبتدئين:
استخدام تنبيهات المتصفح الأصلية يجعل التطبيق يبدو كتطبيق سطح مكتب حقيقي ومثالي لسرعة التنسيق والتواصل بين الفنانين داخل الاستوديو دون تأخير.
