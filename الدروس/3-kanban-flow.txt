=========================================
الدرس الثالث: لوحة المهام وكانبان والتنقل التلقائي
=========================================

مرحباً بك! سنشرح هنا كيف تعمل لوحة المهام التخطيطية (Kanban Board) في الملف (`js/planners.js`) وكيف قمنا ببرمجة صلاحيات النقل والتحول التلقائي للمراجعة.

1. صلاحيات السحب والإفلات (Drag & Drop Permissions)
--------------------------------------------------
في لوحة كانبان الاستوديو، قمنا بتقييد صلاحية سحب ونقل البطاقات يدوياً للأدمن فقط، حتى لا يقوم عضو بنقل مهمة بالخطأ أو التلاعب بحالة المشاريع.
لتحقيق ذلك، نقوم بتفعيل خاصية `draggable` للبطاقات فقط إذا كان دور المستخدم المسجل هو `admin`:
   if (user.role === "admin") {
       card.setAttribute("draggable", "true");
       card.addEventListener("dragstart", (e) => {
           e.dataTransfer.setData("text/plain", task.id);
       });
   }
هذا السطر يعني أن المستخدم العادي لن يتمكن من سحب البطاقة بيده أبداً في المتصفح.

2. نظام المهام الفرعية (Subtasks System)
----------------------------------------
كل كرت مشروع كبير يحتوي على مهام تفصيلية صغيرة (Subtasks).
- يمكن للمنفذين المعينين على المهمة فقط إضافة مهام فرعية جديدة أو وضع علامة "مكتمل" عليها.
- نقوم بحساب نسبة الإنجاز وعرضها بصيغة مئوية من خلال معادلة بسيطة:
   const completedCount = subList.filter(s => s.completed).length;
   const totalCount = subList.length;
   const progressPercent = Math.round((completedCount / totalCount) * 100);

3. برمجة الانتقال التلقائي إلى عمود المراجعة (Auto-Move)
---------------------------------------------------------
هذا هو المنطق الذكي الأهم: عندما ينهي منفذو المشروع كل مهامهم الفرعية بنسبة 100%، يجب أن تتحرك المهمة تلقائياً لعمود "المراجعة" لتنبيه الإدارة.
كيف يحدث هذا؟
عندما يقوم العضو بالضغط على أي تشيك بوكس لمهمة فرعية وتعديل حالتها، يقوم التطبيق بتشغيل دالة التحقق:
   const allCompleted = subList.every(s => s.completed);
   if (allCompleted && subList.length > 0) {
       // تحديث حالة المهمة فوراً في قاعدة البيانات الفايربيس إلى المراجعة
       await update(taskRef, { status: "review" });
       showToast("اكتملت كافة المهام الفرعية وتم نقل الكرت تلقائياً للمراجعة!", "success");
       logActivity("النظام التلقائي", `نقل المشروع [${task.title}] لعمود المراجعة لاكتمال العمل`);
   }
باستخدام دالة `every()` في جافاسكريبت، نتحقق أن كل عنصر في المصفوفة يحتوي على قيمة `completed = true`.

4. الإغلاق المالي والتوزيع
-------------------------
عندما يقرر الأدمن نقل المهمة لعمود "Completed & Paid"، لا نقوم بالنقل فوراً، بل نفتح نافذة منبثقة (Modal) تطلب منه ميزانية المشروع. وبمجرد التأكيد، نقوم بتشغيل كود المنظومة المالية الذي شرحناه في الدرس الثاني ثم ننقل البطاقة برمجياً.

تلميح للمبتدئين:
استخدام الأحداث (Events) وقاعدة البيانات اللحظية يسمح للجميع بمتابعة سير العمل فورياً، فالأدمن يرى البطاقات وهي تتحرك لعمود المراجعة في شاشته لحظة إنجاز العضو لآخر مهمة فرعية لديه!
