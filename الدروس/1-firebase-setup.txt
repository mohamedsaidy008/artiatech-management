=========================================
الدرس الأول: إعداد وتثبيت قاعدة بيانات Firebase Realtime
=========================================

أهلاً بك يا بطل في عالم تطوير الويب الحقيقي! في هذا الملف سنشرح لك كيف قمنا بربط تطبيق استوديو ارتياتك بقاعدة البيانات الفورية (Firebase).

1. ما هو Firebase ولماذا اخترناه؟
---------------------------------
Firebase هي منصة سحابية تقدمها شركة Google. اخترنا منها خدمة "قاعدة البيانات في الوقت الفعلي" (Realtime Database).
ميزة هذه الخدمة أنها سريعة جداً وتقوم بتحديث الشاشة فوراً عند حدوث أي تغيير في البيانات (مثل كتابة رسالة أو إكمال مهمة) دون الحاجة لإعادة تحميل الصفحة.

2. ملف الإعداد (js/firebase-config.js)
--------------------------------------
في هذا الملف قمنا بتهيئة الخدمة باستخدام كود بسيط جداً. لنلقِ نظرة على الأجزاء الهامة فيه:

أ) استيراد مكتبات Firebase (SDK):
نستورد الكود الجاهز من خوادم جوجل مباشرة (CDN) باستخدام نظام المودولات (ES Modules):
   import { initializeApp } from "https://www.gstatic.com/firebasejs/10.8.0/firebase-app.js";
   import { getDatabase, ref, set, get, update, push, remove, onValue } from "https://www.gstatic.com/firebasejs/10.8.0/firebase-database.js";

ب) كائن الإعدادات (firebaseConfig):
هذه هي معلومات الاتصال الخاصة بمشروع استوديو ارتياتك، وهي بمثابة العنوان ومفتاح المرور الذي يسمح للموقع بالاتصال بالخادم:
   const firebaseConfig = {
     apiKey: "AIza...",
     authDomain: "artiatech-management.firebaseapp.com",
     databaseURL: "https://artiatech-management-default-rtdb.firebaseio.com",
     projectId: "artiatech-management",
     ...
   };

ج) تهيئة الاتصال وتصدير الدوال:
نقوم بتشغيل الاتصال البرمجي وتصدير دوال التحكم لنستخدمها في باقي ملفات جافاسكريبت:
   const app = initializeApp(firebaseConfig);
   const db = getDatabase(app);
   export { db, ref, set, get, update, push, remove, onValue };

3. أهم الدوال التي ستستخدمها وكيف تعمل:
--------------------------------------
* ref(db, path): تحدد المسار أو العقدة داخل قاعدة البيانات التي تريد التعامل معها (مثل: `users/user_1` أو `tasks`).
* set(ref, data): تقوم بكتابة بيانات جديدة في المسار المحدد (وتمسح أي بيانات قديمة كانت هناك).
* get(ref): تقوم بقراءة البيانات لمرة واحدة فقط (مفيدة للتحقق من كلمة المرور أثناء تسجيل الدخول).
* update(ref, data): تقوم بتعديل حقول معينة فقط دون مسح باقي البيانات في ذلك المسار.
* push(ref): تنشئ معرفاً عشوائياً فريداً (Unique Key) ومناسب جداً لإضافة رسائل جديدة أو مهام جديدة دون حدوث تعارض.
* remove(ref): تقوم بحذف البيانات من المسار المحدد نهائياً (مثل حذف رسالة شات).
* onValue(ref, callback): مستمع فوري (Listener) يعمل في الخلفية بشكل مستمر، ويقوم بتشغيل الكود الخاص بك فوراً وتلقائياً بمجرد حدوث أي تعديل أو إضافة للبيانات في قاعدة البيانات.

تلميح للمبتدئين:
تذكر دائماً أن مسارات الفايربيس تشبه المجلدات في جهاز الكمبيوتر الخاص بك، فمثلاً `users/user_1/name` يمثل حقل الاسم الخاص بالمستخدم الأول.
